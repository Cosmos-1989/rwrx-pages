回忆叙述的双重视角

文学文本分析与批评 ↗6 分钟阅读

回忆叙述常交织当时经历者的感知与后来讲述者的认识。

概念界定与边界

回忆叙述常交织当时经历者的感知与后来讲述者的认识。分析须确认判断产生于哪个时间位置；后见之明可以重释往事，却不能当作人物当年已经明确拥有的意识。

两个时点与信息范围

经历时的“我”处在事件之中，其知识和判断受到当时条件限制；讲述时的“我”则可能拥有后来的经验，并重新选择、排序和评价往事。叙述人称相同，并不消除二者的差异。[1]

这一划分是叙述声音与聚焦的具体应用：分析要说明某个判断属于当时的感知，还是后来回望的理解。

辨析层面 判断依据
经历时点 人物当时所见、所感与能够知道的事情。
讲述时点 后来回顾时的选择、评价与知识。
叠合表达 同一语句可能以成年人的措辞组织童年的感受，不宜机械二分。

分析程序

  1. 圈出“那时”“现在”“后来才知”等时间标记。
  2. 判断每个评价需要什么经验或知识。
  3. 比较当时感受与后来理解是否一致，或是否形成温情、反思、讽刺。
  4. 引用能显示时点关系的措辞，而不是仅凭作者年龄推断。

在措辞中识别时点变化

《从百草园到三味书屋》开篇以“现在”“但那时”区分两个评价位置；园子的平常面貌与儿童的乐园经验因而能够同时成立。

美女蛇故事之后的“直到现在”把童年的愿望带回讲述时点，形成回顾的语气。解释应依据这些可定位的时间与评价线索。

实例细读

百草园开篇先说园子似乎只有野草，随即转为“但那时却是我的乐园”。平常面貌与儿童乐趣不是互相否定，而是评价位置不同。

童年未必会用成年写作者的全部措辞来描述自己；分析声音与经验的差别，有助于解释回忆散文为何既有亲历感又有回望距离。

打橘子 · 第1题选析

研习任务：下列对文本相关内容和艺术特色的分析鉴赏，正确的一项是（　） A．作者在叙述打橘子时插入的“岂不也有点无聊吗”“对于橘子树未免有点说不过去哩”两句，追悔往事，流露出人到中年时的心境。 B．文本中画横线语句描绘旧居亭台池馆衰败的景况，营造出沉郁悲凉的意境，以今昔的反差凸显“我”的怅惘心情。 C．“我”重访旧居时摘下橘子带回，最终却“只当是丢了”，这一情节富于象征意味，表明“我”从此也丢下了心中的怀恋。 D．文本以作者的回忆为主要内容，写法与归有光的《项脊轩志》有相似之处，都在对平凡事物和日常琐事的叙写中寄寓深情。

A项辨析：A项不符合。“岂不也有点无聊吗”肯定寻橘过程的乐趣，“说不过去”是对拉下枝叶的诙谐自责，不能概括为中年追悔。回顾叙述可以重现往日口吻，也可含讲述者调侃，不宜将二者机械割裂。

文本依据：“虽觉麻烦，亦可笑乐。”；“对于橘子树未免有点说不过去哩。”

B项辨析：B项不符合。荒落与陌生确能关联怅惘，但“不必说”“有点”等措辞较节制，随后又见熟悉的红橘，不能将这段一笔概括为沉郁悲凉。

文本依据：“亭台池馆荒落不必说，只隔得半年已经有点陌生了。”；“眼下觉得怪熟的，满树离离的红橘子。”

端午的鸭蛋 · 第2题选析

研习任务：关于文中画横线的语句，下列说法不正确的一项是（） A．句子①以“莫名其妙”和反问呈现对符咒的不解与疑问，带有回忆童年时的谈话口吻，不宜仅凭此句把发言完全归给儿时的“我”。 B．句子②从标点上来看，该句基本上是一句一断，大有生活中说一句停一下，略想想后再说的神态，自然真实，让人倍感亲切。 C．句子③异乡人虽然“称道高邮鸭蛋”，但故乡却是一个“穷地方”，所以作者“不大高兴”，体现作者对故乡浓厚的情感。 D．句子④红油冒出来，本来只能观其形，用上“吱”字，仿佛能闻其声，这一声，让吃咸鸭蛋的过程变得有声有色，有情有趣。

A项辨析：“莫名其妙”和反问表现不解，也形成面对面交谈的语气。作品是回忆叙述，成年讲述者的表达与儿时经验可以叠合，不能单靠口语形式断定发言完全属于童年自我。

文本依据：“上面用朱笔画些莫名其妙的道道，这就能辟邪么”。

C项辨析：“好像我们那穷地方就出鸭蛋似的”重在“就”：不满的是别人将家乡仅仅等同于鸭蛋。不能把插入的自谦说法“穷地方”当成不高兴的直接原因。

文本依据：“我对异乡人称道高邮鸭蛋，是不大高兴的，好像我们那穷地方就出鸭蛋似的”。

儿童经验与回忆者评价

儿童视角常体现在感官注意、因果理解和经验边界；成人回忆者则可能补充命名、比较和评价。两层声音可以交织，不能只见第一人称就认定全部语言是儿童即时独白。

《荒野的声音》将童年感官经验、长辈教导和拟人想象交织；《端午的鸭蛋》既回味童年趣事，也以成年人的语言评说乡味。朗读和艺术赏析应辨明这种距离变化。联想解释材料间的触发关系，想象解释对未直接感知情景的构造。

与妻书 · 回忆作用

研习任务：信中夫妻相处的回忆为什么不是游离于主旨的闲笔？

生活细节使爱有可见内容：空间路线、梅影、并肩携手和低声谈话共同构成亲密经验，说明作者为何反复说不能忘。抽象感情由记忆中的动作与景物落实。

文本依据：“窗外疏梅筛月影”；“并肩携手，低低切切”。

承诺与沉默显出选择代价：妻子要求远行相告，作者曾答应，却因担忧其承受能力不能开口。前后照应使歉疚有具体根由，与诀别书解释衷情的写作目的相接。

文本依据：“望今后有远行，必以告妾”；“及与汝相对，又不能启口”。

易误辨析与迁移

不能把每一句成熟修辞都视为成年人的否定态度，也不能把所有第一人称感叹当作当年的原话。是否存在反思或讽刺，应由语气与结构证明。

不能机械划分所有句子

一个句子也可能兼具儿童感受与成年人的措辞组织。区分时点是分析工具，不要求把每句话强行归入互不相容的类别。认定作者的写作心理，还需要文本之外的证据。
