九品中正与科举的形成

古代汉语基础 ↗3 分钟阅读

概念界定与边界

九品官人法是魏晋以来由中正品评人物并供选官参考的制度。隋唐分科考试则用相应科目的考核结果选取人才。前者的核心材料是中正所定的品第和评语，后者的核心材料是考试与录取记录。

《三国志·陈群传》将创立九品官人法归于曹魏陈群。中正是担任人物品评的官员。品第区分受评者的等次，评语记述所见的德行与才具。魏晋以来，中正品评、州郡荐举和官府征聘可以并行。北齐仍可见设置中正与策试秀才并存的记载。

隋唐之际，旧有选官方式发生调整。杜佑《通典》和王定保《唐摭言》把进士一科追溯到隋炀帝时。唐代文献中的进士、明经等常科已见按科考核和定期贡送。解释“科举形成”时，可分别核对一科设置、持续施行和考试程序逐渐完备的证据。

察举与策问提供了分别辨认荐举和考核的例子，也可用来理解魏晋选任中不同环节的作用。

选取方式 主要线索 直接说明的事项
察举 官员按孝廉、秀才等名目荐举 人物由谁荐举，以何名目报送
中正品评 中正为人物定品并作评语 人物品第，可供有关官署选任参考
分科考试 按科目设题、较等、录取 应考科目及录取结果

分析程序

  1. 先区分所叙时代和记述时代。为旧制写的奏疏、后人的制度志，记录角度可能有别。
  2. 找出谁荐举、谁评品、谁考试和谁授官，再顺次排列事件。
  3. 将人物品第、科场等第和官职品秩列在不同栏。古书中的“品”或“第”须与搭配同读。
  4. 如要说明形成时间，先明确所指的制度要件，再查相应诏书、传记或制度志。

实例细读

刘毅为何批评中正品评

《晋书·刘毅传》载其上疏批评当时品评偏重权势，概括为“上品无寒门，下品无势族”。这句话说明奏疏作者认为品第受门第和请托干预。它是针对制度运作的批评，解释陈群最初如何定制还要查早期记载。

原典或实物资料

鲍照怎样写人生际遇

原文“人生亦有命，安能行叹复坐愁”

鲍照是南朝宋人。诗先写水流各处，继而以“人生亦有命”自劝。教材用门第限制解释诗人所处环境，诗句本身写的是对不平遭际的感受。若要落实鲍照具体的入仕经过和所获品第，应另找传记或选任材料。

孟浩然如何向张丞相表达求仕之意

原文“欲济无舟楫，端居耻圣明”

“欲济”与“无舟楫”相接，写想有所作为却缺少凭借。面向张丞相的题目和“羡鱼”一联，使诗中的求仕之意可以理解为对援引的期待。

唐已有分科考试，士人仍可向人陈述志向、求荐。诗只交代赠诗对象和求仕意愿，人物究竟通过哪一制度入仕，须有另文可据。

易误辨析与迁移

人物品第用于评量人选，官职品秩用于标示官员等次。解读传记时，须问评定的对象是人、官还是试卷。

先秦礼书中的乡举、贡士是理解后世用语的材料。《礼记·王制》有“进士”一词，所处的是礼书叙述的学校选士程序。隋唐的进士作为考试科目，需要据后世制度材料解释。
