侧面描写与烘托

2 分钟阅读

侧面烘托通过他人的反应、相关环境或结果描写，使主要对象的特征间接显现。它与正面描写的区别在呈现路径，不在是否含蓄。物可以烘托人，人也可以烘托物，不要求一律建立象征性的物性投射。

分析原则

侧面烘托以相关反应或环境使对象间接显现。

概念与辨析

辨析对象 判断依据与适用边界
正面描写 直接写对象的动作、语言、外貌或心理；动作显心理仍可属于正面描写。
侧面反应 写观察者的反应，使未被直接描写的力量或特征可感。
环境衬托 环境同人物处境发生关系，突出心境或选择；不必都有象征义。

分析程序

  1. 确定被表现的主要对象。
  2. 确认文本直接描写的是对象还是相关反应。
  3. 说明两者之间的因果或感知联系。
  4. 指明被突出的是何种特征。

实例细读

《荒野的声音》写“我”用被子包头，借听者反应表现儿童感到夜声密集的体验，不能据此认定想象中的一切声响都真实存在。《邓芝使吴》森严武士和沸腾油锅构成危险处境，邓芝的镇定因对照而突出。

易误辨析与迁移

同一语句可能既细写物又显人物感受。不能仅因“手机颤动”是写实细节，就否认它在《打野》中烘托寻找亲人的焦虑。

对比与衬托关注关系；人物塑造关注评价的证据。
