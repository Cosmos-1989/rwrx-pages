6 分钟阅读

课程概要

以分析性阅读、文本证据与规范表达为主线。四周精读八篇材料，每周五个训练日。

每天约30分钟。用纸笔或电子笔记完成任务，按训练日和题号记录，再展开参考答案，核对证据与推理。

规范一：分析性阅读批注规范

1、批注范围

先读全文，再选择能够解释观点、结构、人物或表达的词句。每篇的必做范围已列在【任务二批注记录区】B1起的清单中；逐项完成清单，不按画线多少评价批注。

文本部位

优先标记什么

批注要回答什么

论述与说明

中心判断、概念界定、实例、引文、结论

在讨论什么？这项证据支持哪一判断？中间如何联系？

转折与限定

但是、因此、可能、只、几乎、如果等关系或范围词

前后是何种关系？删改这个词，判断的范围或强度怎样变化？

小说与散文

关键言行、心理、环境、叙述视角、反复物象、情节转折

文本直接写了什么？由此能怎样理解人物或主题？依据是否充分？

多材料与前后文

同一概念的不同所指、相近观点、相反评价、相互照应处

比较对象与标准是否相同？彼此是补充、对照，还是修正？

疑问与不一致

看似矛盾、来源不明、缺条件或推断跨度大的判断

疑问具体指向哪句话？什么上下文能支持、限制或否定它？

2、书写位置

任务一：通读后的问题、线索或关系图，写在本篇文后的【任务一作答区】T1.1、T1.2。

任务二：在正文相应词句下圈画，并在旁边写B1、B2等编号；短引文和解释统一写在【任务二批注记录区】同号位置。

任务三、四：按每日任务单完成【精读练习】，直接写在各题下方。

阅读边栏：用于随手记关键词或画箭头，可作草稿；边栏“阅读提示”帮助观察，必做内容以B项清单为准。

任务作答页用W1D1等训练日编号与篇名定位；书后参考沿用相同编号。无需查找页码。

规范二：符号与有效标准

3、批注符号

符号

用途

落笔要求

○

观点或判断

圈出核心谓语或判断句，写清对象与主张。

△

证据或论据

摘关键事实、行动、例子或引文，标明支持对象。

→

逻辑或结构

连接两处文字；箭头旁标“因果”“对照”“递进”“照应”等关系。

？

疑问或待证

写具体疑点与核查方向，不能只画问号。

！

条件或限定

标范围、程度或转折词，说明它限制了什么。

★

手法或表达

点明具体写法，并解释在当前语境中的作用。

4、一条有效批注的标准

位置＋短引文＋解释＋联系

位置包含材料号、段号或指定范围；每次摘录1—2处关键词句，每处不超过15字；解释约30—50字，写清它与观点、人物、结构或主题的联系。

合格标准：范围找对；引文不改原意；解释由证据推出；关系说具体。只抄原句、只写术语或“写得好”“很生动”，都不构成完整批注。

示例：《驱遣我们的想象》第7段

仅写“运用了议论，写得好”不能解释这句话。可写：“必须驱遣我们的想象”中的“必须”提出必要条件：读者要借助想象透过文字接触意境，才能实现鉴赏目的。

5、引文与推断的界限

引文加引号，概述不改变原意。先辨明文本直接呈现的内容，再说明可以作出的推断。人物的话、叙述者的评价、作者主张应分别辨认；有疑问时保留条件和限度。

书后参考给出一种可由文本支持的写法及分析路径。选用不同的短引文或表述，只要位置准确、推理完整、结论适度，同样可以成立。

规范三：答题规范

1、答题要求

术语必须服务于具体分析。

2、答题步骤

先辨认设问任务，再选择必要步骤。

信息类文本阅读主线

文学类文本阅读主线

标注关键句 → 合并同类信息 → 提炼核心词 → 说明信息关系

人物与情节 → 环境与细节 → 情感及主题 → 表达方式与效果

答题第一步：

判断设问类型

答题第二步：

按步骤完成文本分析

答题第三步：

按规范答题

信息筛选 / 判断

定位对应处 → 比较对象、范围、条件与语气 → 判断一致性

保留限定词；不把推测当事实。

内容概括

确定范围 → 找主要对象与行动 → 合并同类项

分点简洁，各点不重复。

论证分析

辨认论点 → 划分层次或找方法 → 说明论据怎样支持论点

思路写推进；方法写具体论据及证明作用。

词句 / 手法赏析

解释语境义 → 指出具体表达 → 分析人物、情感或意境

引用关键词；不只罗列术语。

标题 / 作用分析

解释具体所指 → 联系情节或结构 → 归纳主题意味

由具体到整体；避免无据拔高。

比较 / 联读

确定同一比较角度 → 两文分别举证 → 概括异同

两方都有分析，比较维度一致。

观点 / 迁移应用

明确判断 → 选择相关证据 → 解释联系 → 限定结论

例子具体；观点与证据之间有推理。

作答前：圈出对象、范围与要求。

作答时：每点表达一个判断，并给出依据和解释。

作答后：核对是否遗漏问题、重复内容或扩大结论。
