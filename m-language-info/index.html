知识研习

拟声与语音象征：拟声词以约定化的语音形式摹写声音；语音象征则是声音形式与大小、速度、质感等经验之间形成的联想。二者不能等同于“某个声母天然表达某种感情”。重叠、音节数量和停顿还会参与听觉效果。

汉字构形与六书：六书是传统文字学解释汉字的分类框架，通常列为象形、指事、会意、形声、转注、假借。四种构字方式与转注、假借的性质并不完全相同。形声字由提示义类的形旁和提示读音的声旁构成，但现代字形、字音与初始结构之间可能已有变化。

规范字形与词形：字形规范关乎字的写法，词形规范关乎固定词语采用哪些字。错字、别字和异形词是不同问题：错字不合规范字形，别字以另一字误代，异形词则涉及历史上并行的写法及其整理。

成语的语境适配：成语具有相对固定的结构和约定化意义。适配判断须综合核心意义、适用对象、感情色彩、语体、搭配与句法位置；意义相近并不保证可在同一空缺中互换。

近义词辨析：近义词共享部分概念意义，但可在语义范围、程度、搭配对象、句法功能和语体色彩上不同。辨析的目标是解释当前语境中的选择依据，而非罗列脱离语境的区别。

词类与语法功能：词类主要依据词的语法功能划分，并参考意义和形态。能否独立充当句子成分、能与哪些词组合，是判断的重要依据。同一形式在不同用法中可能分属不同词类，不能只按字面意义判类。

名词性状化：“很中国”“很青春”等表达将名词所关联的典型性质凸显为可分程度的特征。名词与程度副词的组合可在特定构式中成立，其可接受性依赖语义转化和使用语境。

标点的层级与功能：标点既标示语段停顿和语气，也标识语段的性质与组织关系。点号主要表现停顿与语气，标号主要标示特定功能。正确使用依赖句法层次和表达意图，不能仅按朗读停顿长短决定。

书名号的使用：书名号标示书籍、篇章、报刊、文件、影视等作品的名称。名称所指的对象性质决定是否使用，不能因为专名较长、较重要或在句中需要强调就加书名号。

句内括号与句外括号：句内括号对句中某一成分作注释或补充，通常紧接被注释部分；句外括号补充说明整个句子或语段，通常置于句末点号之后。辨认其说明对象比记忆固定位置更重要。

冒号的统摄范围：冒号表示提示性停顿，可引出说明、列举、引语或总结。其统摄范围取决于句子和段落结构。同一句中连续使用冒号易使层次含混，宜改写；分项分段则须按各自结构判断。

破折号的功能：破折号可标示解释说明、话题转换、语意递进、声音延长或话语中断等关系。不同功能需从前后语段的关系及交际情境判断，不能只凭符号形状作答。

点号与句末语气：顿号、逗号和分号主要对应不同结构层次的停顿；句号、问号和叹号还体现整句的语气与交际功能。句子中含疑问词，并不必然构成直接发问。

句子成分与主干：句子成分是按句法关系识别的主语、谓语、宾语、定语、状语和补语等。提取主干有助于发现搭配或成分问题，但不能把被删去的修饰语都当成可有可无。

定语、状语与语序：修饰语次序受到语义范围、句法层次和信息组织的共同制约。时间、处所、方式等成分常有习惯性排序，但范围和焦点变化可引起不同次序，不宜用口诀代替句法分析。

复句关系与关联词：复句由两个或多个有相对独立意义的分句组成，分句间可有并列、承接、递进、选择、转折、因果、假设、条件等关系。关联词是关系线索，其解释仍依赖具体命题内容。

借代：借代借助对象之间可辨认的相关关系，用一项指称另一项，如以局部代整体、特征代对象、工具代使用者。它重在指称转移；比喻则主要以相似关系重组理解，二者不能只凭有没有“像”来区分。

对偶、对仗与对联：对偶以字数相当、结构相近和意义相关的两个语段成对组织表达。对仗常对词性、结构、意义类别和声调有更细要求。对联则是具有特定应用和独立文体性质的一副联语，不能将一般对偶都称为对联。

设问与反问：设问以提出问题并作答或引导后文的方式组织论述；反问用疑问形式加强可推知的判断。真实询问、设问和反问在交际任务上不同，不能以是否出现问号一概判定。

双关：双关利用同音、近音或同一形式的多重意义，使一个表达同时关联两层意义。两层意义都须在具体语境中获得支持，不能因为词典中存在多个义项就断定用了双关。

概念的内涵与外延：内涵是概念所规定的属性，外延是符合这些规定的对象范围。概念外延可有全同、包含、交叉或全异关系。内涵增加、外延缩小的对应只在同一论域和属性累加等条件下成立，不是任意两个概念都具有的反比公式。

定义与分类：属加种差定义用上位概念确定类别，再以区别性条件限定对象。定义须避免过宽、过窄、循环和含混。描述特点、表达态度或举例，并不自动构成完整定义。

充分条件与必要条件：若P成立足以保证Q成立，P是Q的充分条件，Q是P的必要条件。由P推出Q，可作肯定前件和否定后件的有效推理；肯定后件或否定前件并不能单独保证相应结论。充分、必要和充要关系应分别表述。

逻辑基本规律：同一律要求同一论证中概念和命题保持确定含义；矛盾律不允许在同一时间、方面和意义下同时肯定与否定同一命题；经典逻辑的排中律在已确定的命题及其否定之间不留第三种真值。三者均以明确论域和命题为前提。

常见论证谬误：非形式谬误关乎论证的相关性、证据强度、概念使用或论辩规则。稻草人歪曲对方主张，虚假两难遗漏合理选项，滑坡论证在缺乏充分支持时把连锁后果视为必然，诉诸情绪则以情绪动员替代有关理由。

信息结构与焦点：信息结构考察话语如何组织已知与新信息、话题与说明、背景与焦点。语法主语不必等同于话题，句末也不总是唯一焦点。语序、重音、句式和上下文共同影响信息呈现。

礼貌与面子：礼貌研究关注语言形式如何协调人际关系。面子理论区分获得认同的需要与保持行动自主的需要；它是分析视角，并不保证所有文化和场合都采用同一策略。直接程度与礼貌程度也不形成简单反比。

人称代词的指称：人称代词的所指由说话者、受话者和语境共同确定。特指与泛指关乎对象是否确定，包括式与排除式关乎“我们”是否包含听者，二者是不同的分类维度。

信息类文本的文体功能：信息类文本是阅读教学中按主要功能形成的集合，包含说明、论述、新闻等多种文体。它不是排斥叙事、形象或情感的单一体裁；分析须同时确定文本传递的信息、提出的主张及其组织方式。

说明对象、方法与顺序：说明围绕事物或事理展开，可借定义、分类、比较、数据、例子、图示等方式使对象清楚可理解。时间、空间与逻辑顺序属于组织方式；说明方法与说明顺序处在不同分析层面。

多材料阅读：多材料文本围绕共同问题组织不同来源、体裁或形式的信息。材料可以互补、对照、递进，也可能相互冲突。整合必须保留出处、立场、时间和证据层级，不能把异质信息拼成无差别的事实。

分析性阅读：分析性阅读在理解内容的基础上，考察概念、结构、证据、推理与评价标准。整体阅读和局部细读相互校正；它不是必须按固定顺序执行的一套动作。

句群与语篇关系：句群是围绕相对完整意思组织的一组句子，其界限不必与排版段落重合。句间可形成并列、承接、递进、转折、因果、解说等关系；同一语段可能同时具有局部关系和整体功能。

语句补写、衔接与复位：补写、排序和复位要求恢复局部句子与整体语篇的联系。空缺受前后内容、话题、指称、逻辑、句式和字数共同约束。满足其中一个条件并不代表答案成立。

因果关系与因果推断：因果解释说明某因素怎样影响结果；相关、先后或共同出现本身并不足以建立因果。分析需考虑作用机制、其他可能原因、条件和证据来源，并区分文本声称的因果与已经验证的因果。

归纳概括与证据强度：归纳由若干观察支持更一般的判断，其可靠性与样本范围、代表性、独立性以及反例情况有关。多处同类证据可增强支持，但不能仅凭数量证明结论必然成立。

论证方法：论证方法是材料支持主张的组织与推理方式。举例、引用、对比、类比和因果分析可承担不同任务，名称相同并不保证证据效力相同。说明性比喻帮助理解，类比论证还须提供推断根据。

图表与图像阅读：图表把数量、结构或空间关系转化为视觉形式，图像赏析则结合可见细节讨论表现方式。两类任务均须先准确描述可见信息，再作解释，不能用主题推测代替观察。

主观题的推导与组织：主观题作答应把文本证据、所用概念、推理关系和结论组织为可以检查的解释。教学中的作答要点用于显示答案结构，不等同于未经公布的官方评分细则。

阅读与论证

以文本证据与阅读推论明确判断依据，以主观题的推导与组织连接概念、推理与分项作答。

拟声与语音象征1 处阅读条目 →知识研习 ↗

拟声与语音象征：拟声词以约定化的语音形式摹写声音；语音象征则是声音形式与大小、速度、质感等经验之间形成的联想。二者不能等同于“某个声母天然表达某种感情”。重叠、音节数量和停顿还会参与听觉效果。

汉字构形与六书1 处阅读条目 →知识研习 ↗

汉字构形与六书：六书是传统文字学解释汉字的分类框架，通常列为象形、指事、会意、形声、转注、假借。四种构字方式与转注、假借的性质并不完全相同。形声字由提示义类的形旁和提示读音的声旁构成，但现代字形、字音与初始结构之间可能已有变化。

规范字形与词形1 处阅读条目 →知识研习 ↗

规范字形与词形：字形规范关乎字的写法，词形规范关乎固定词语采用哪些字。错字、别字和异形词是不同问题：错字不合规范字形，别字以另一字误代，异形词则涉及历史上并行的写法及其整理。

成语的语境适配1 处阅读条目 →知识研习 ↗

成语的语境适配：成语具有相对固定的结构和约定化意义。适配判断须综合核心意义、适用对象、感情色彩、语体、搭配与句法位置；意义相近并不保证可在同一空缺中互换。

近义词辨析1 处阅读条目 →知识研习 ↗

近义词辨析：近义词共享部分概念意义，但可在语义范围、程度、搭配对象、句法功能和语体色彩上不同。辨析的目标是解释当前语境中的选择依据，而非罗列脱离语境的区别。

词类与语法功能1 处阅读条目 →知识研习 ↗

词类与语法功能：词类主要依据词的语法功能划分，并参考意义和形态。能否独立充当句子成分、能与哪些词组合，是判断的重要依据。同一形式在不同用法中可能分属不同词类，不能只按字面意义判类。

名词性状化1 处阅读条目 →知识研习 ↗

名词性状化：“很中国”“很青春”等表达将名词所关联的典型性质凸显为可分程度的特征。名词与程度副词的组合可在特定构式中成立，其可接受性依赖语义转化和使用语境。

标点的层级与功能1 处阅读条目 →知识研习 ↗

标点的层级与功能：标点既标示语段停顿和语气，也标识语段的性质与组织关系。点号主要表现停顿与语气，标号主要标示特定功能。正确使用依赖句法层次和表达意图，不能仅按朗读停顿长短决定。

书名号的使用1 处阅读条目 →知识研习 ↗

书名号的使用：书名号标示书籍、篇章、报刊、文件、影视等作品的名称。名称所指的对象性质决定是否使用，不能因为专名较长、较重要或在句中需要强调就加书名号。

句内括号与句外括号1 处阅读条目 →知识研习 ↗

句内括号与句外括号：句内括号对句中某一成分作注释或补充，通常紧接被注释部分；句外括号补充说明整个句子或语段，通常置于句末点号之后。辨认其说明对象比记忆固定位置更重要。

冒号的统摄范围1 处阅读条目 →知识研习 ↗

冒号的统摄范围：冒号表示提示性停顿，可引出说明、列举、引语或总结。其统摄范围取决于句子和段落结构。同一句中连续使用冒号易使层次含混，宜改写；分项分段则须按各自结构判断。

破折号的功能1 处阅读条目 →知识研习 ↗

破折号的功能：破折号可标示解释说明、话题转换、语意递进、声音延长或话语中断等关系。不同功能需从前后语段的关系及交际情境判断，不能只凭符号形状作答。

点号与句末语气1 处阅读条目 →知识研习 ↗

点号与句末语气：顿号、逗号和分号主要对应不同结构层次的停顿；句号、问号和叹号还体现整句的语气与交际功能。句子中含疑问词，并不必然构成直接发问。

句子成分与主干1 处阅读条目 →知识研习 ↗

句子成分与主干：句子成分是按句法关系识别的主语、谓语、宾语、定语、状语和补语等。提取主干有助于发现搭配或成分问题，但不能把被删去的修饰语都当成可有可无。

定语、状语与语序1 处阅读条目 →知识研习 ↗

定语、状语与语序：修饰语次序受到语义范围、句法层次和信息组织的共同制约。时间、处所、方式等成分常有习惯性排序，但范围和焦点变化可引起不同次序，不宜用口诀代替句法分析。

复句关系与关联词1 处阅读条目 →知识研习 ↗

复句关系与关联词：复句由两个或多个有相对独立意义的分句组成，分句间可有并列、承接、递进、选择、转折、因果、假设、条件等关系。关联词是关系线索，其解释仍依赖具体命题内容。

借代1 处阅读条目 →知识研习 ↗

借代：借代借助对象之间可辨认的相关关系，用一项指称另一项，如以局部代整体、特征代对象、工具代使用者。它重在指称转移；比喻则主要以相似关系重组理解，二者不能只凭有没有“像”来区分。

对偶、对仗与对联1 处阅读条目 →知识研习 ↗

对偶、对仗与对联：对偶以字数相当、结构相近和意义相关的两个语段成对组织表达。对仗常对词性、结构、意义类别和声调有更细要求。对联则是具有特定应用和独立文体性质的一副联语，不能将一般对偶都称为对联。

设问与反问1 处阅读条目 →知识研习 ↗

设问与反问：设问以提出问题并作答或引导后文的方式组织论述；反问用疑问形式加强可推知的判断。真实询问、设问和反问在交际任务上不同，不能以是否出现问号一概判定。

双关1 处阅读条目 →知识研习 ↗

双关：双关利用同音、近音或同一形式的多重意义，使一个表达同时关联两层意义。两层意义都须在具体语境中获得支持，不能因为词典中存在多个义项就断定用了双关。

概念的内涵与外延1 处阅读条目 →知识研习 ↗

概念的内涵与外延：内涵是概念所规定的属性，外延是符合这些规定的对象范围。概念外延可有全同、包含、交叉或全异关系。内涵增加、外延缩小的对应只在同一论域和属性累加等条件下成立，不是任意两个概念都具有的反比公式。

定义与分类1 处阅读条目 →知识研习 ↗

定义与分类：属加种差定义用上位概念确定类别，再以区别性条件限定对象。定义须避免过宽、过窄、循环和含混。描述特点、表达态度或举例，并不自动构成完整定义。

充分条件与必要条件1 处阅读条目 →知识研习 ↗

充分条件与必要条件：若P成立足以保证Q成立，P是Q的充分条件，Q是P的必要条件。由P推出Q，可作肯定前件和否定后件的有效推理；肯定后件或否定前件并不能单独保证相应结论。充分、必要和充要关系应分别表述。

逻辑基本规律1 处阅读条目 →知识研习 ↗

逻辑基本规律：同一律要求同一论证中概念和命题保持确定含义；矛盾律不允许在同一时间、方面和意义下同时肯定与否定同一命题；经典逻辑的排中律在已确定的命题及其否定之间不留第三种真值。三者均以明确论域和命题为前提。

常见论证谬误1 处阅读条目 →知识研习 ↗

常见论证谬误：非形式谬误关乎论证的相关性、证据强度、概念使用或论辩规则。稻草人歪曲对方主张，虚假两难遗漏合理选项，滑坡论证在缺乏充分支持时把连锁后果视为必然，诉诸情绪则以情绪动员替代有关理由。

信息结构与焦点1 处阅读条目 →知识研习 ↗

信息结构与焦点：信息结构考察话语如何组织已知与新信息、话题与说明、背景与焦点。语法主语不必等同于话题，句末也不总是唯一焦点。语序、重音、句式和上下文共同影响信息呈现。

礼貌与面子1 处阅读条目 →知识研习 ↗

礼貌与面子：礼貌研究关注语言形式如何协调人际关系。面子理论区分获得认同的需要与保持行动自主的需要；它是分析视角，并不保证所有文化和场合都采用同一策略。直接程度与礼貌程度也不形成简单反比。

人称代词的指称1 处阅读条目 →知识研习 ↗

人称代词的指称：人称代词的所指由说话者、受话者和语境共同确定。特指与泛指关乎对象是否确定，包括式与排除式关乎“我们”是否包含听者，二者是不同的分类维度。

信息类文本的文体功能1 处阅读条目 →知识研习 ↗

信息类文本的文体功能：信息类文本是阅读教学中按主要功能形成的集合，包含说明、论述、新闻等多种文体。它不是排斥叙事、形象或情感的单一体裁；分析须同时确定文本传递的信息、提出的主张及其组织方式。

说明对象、方法与顺序1 处阅读条目 →知识研习 ↗

说明对象、方法与顺序：说明围绕事物或事理展开，可借定义、分类、比较、数据、例子、图示等方式使对象清楚可理解。时间、空间与逻辑顺序属于组织方式；说明方法与说明顺序处在不同分析层面。

多材料阅读1 处阅读条目 →知识研习 ↗

多材料阅读：多材料文本围绕共同问题组织不同来源、体裁或形式的信息。材料可以互补、对照、递进，也可能相互冲突。整合必须保留出处、立场、时间和证据层级，不能把异质信息拼成无差别的事实。

分析性阅读1 处阅读条目 →知识研习 ↗

分析性阅读：分析性阅读在理解内容的基础上，考察概念、结构、证据、推理与评价标准。整体阅读和局部细读相互校正；它不是必须按固定顺序执行的一套动作。

句群与语篇关系1 处阅读条目 →知识研习 ↗

句群与语篇关系：句群是围绕相对完整意思组织的一组句子，其界限不必与排版段落重合。句间可形成并列、承接、递进、转折、因果、解说等关系；同一语段可能同时具有局部关系和整体功能。

语句补写、衔接与复位1 处阅读条目 →知识研习 ↗

语句补写、衔接与复位：补写、排序和复位要求恢复局部句子与整体语篇的联系。空缺受前后内容、话题、指称、逻辑、句式和字数共同约束。满足其中一个条件并不代表答案成立。

因果关系与因果推断1 处阅读条目 →知识研习 ↗

因果关系与因果推断：因果解释说明某因素怎样影响结果；相关、先后或共同出现本身并不足以建立因果。分析需考虑作用机制、其他可能原因、条件和证据来源，并区分文本声称的因果与已经验证的因果。

归纳概括与证据强度1 处阅读条目 →知识研习 ↗

归纳概括与证据强度：归纳由若干观察支持更一般的判断，其可靠性与样本范围、代表性、独立性以及反例情况有关。多处同类证据可增强支持，但不能仅凭数量证明结论必然成立。

论证方法1 处阅读条目 →知识研习 ↗

论证方法：论证方法是材料支持主张的组织与推理方式。举例、引用、对比、类比和因果分析可承担不同任务，名称相同并不保证证据效力相同。说明性比喻帮助理解，类比论证还须提供推断根据。

图表与图像阅读：图表把数量、结构或空间关系转化为视觉形式，图像赏析则结合可见细节讨论表现方式。两类任务均须先准确描述可见信息，再作解释，不能用主题推测代替观察。
