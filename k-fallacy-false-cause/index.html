错误因果

概念界定与边界

错误因果指把未得到充分支持的因果判断用作论证理由。两事先后发生或共同变化，可以提出因果假设，却不足以排除第三因素、反向作用和偶然性。由“甲先于乙发生”直接推出“甲导致乙”，是其中一种形式。

阅读选项时若把原文的因果方向写反，首先应指出关系转述错误；只有选项进一步凭这个错误关系支持结论，才形成因果论证的谬误。参见因果关系与因果推断。

分析程序

  1. 分别写出被说成“原因”和“结果”的事件，核对时间、主体与条件。
  2. 找出论者实际使用的证据，区分先后、相关、机制说明与干预证据。
  3. 检查共同原因、反向因果和选择偏差等竞争解释，说明为何不能直接断定原因。
  4. 按证据强度修订结论，保留“可能”“有助于”等必要限定。

实例细读

礼貌与能耗

《对AI说“谢谢”》讨论对智能工具说“谢谢”的效率与人文习惯。若仅因某时段礼貌用语增加且能耗上升，便断言前者造成全部增量，尚需控制访问量、设备负载等变量。

照料与树木生长

《种树郭橐驼传》叙写他植者反复扰动树根，意在说明不合生长习性的干预可能伤树。若只因一次照料之后树木枯萎，就断言那次照料造成枯萎，仍须排查土壤、病害、天气等其他原因，并说明该措施如何影响生长。

易误辨析与迁移

评价因果判断应核查文献所给的机制、对照或反事实证据，再比较其他解释是否足以削弱当前结论。
