碗的记忆

吴文君散文阅读选编15 分钟阅读

不同的碗保存生活方式、审美经验与人生记忆；当亲人老去、相聚减少，回忆让作者重新认识平常日子中的关怀与滋养，形成珍赏、眷恋和失落交织的时间感。

导读

文体与题材：记叙性散文

作者简介：吴文君，当代作家。本文由家庭中关于器物的谈话，展开对亲人、日常生活与时间的回忆。

文本出处：吴文君《碗的记忆》，选自《散文》2023年10月刊，有删改。

内容脉络：由与W谈酒杯，作者回忆小镇粗瓷碗与上海玲珑碗所联系的童年生活，再经由与Z老师的谈话和后来用碗的经历思考器物之美与时间。亲人晚年改用方便的碗，旧日团聚也逐渐消散；结尾回到当下母子对话，重新认识过去未曾留意的亲情滋养。

内容主旨：不同的碗保存生活方式、审美经验与人生记忆；当亲人老去、相聚减少，回忆让作者重新认识平常日子中的关怀与滋养，形成珍赏、眷恋和失落交织的时间感。

阅读重点：辨认器物的材质、使用场景及其联系的人事，区分审美价值、地域生活与亲情记忆；把“简朴与精致”的感慨放回亲人老去和结尾回看的语境。

第1题 · 器物价值

题目性质

选编题。

“碗”对“我”而言，除了实用价值，还有哪些价值？请简要概括。

参考答案1展开 / 收起

参考作答

  1. 情感价值：粗瓷碗中的热粥、奶奶家的玲珑碗，联系着外公的关怀与家人相聚，保存了“我”对亲人的情感。
  2. 地域文化价值：小镇粗瓷碗与上海青花碗连同借碗、饮食、作息等习惯，记录了不同地域的日常生活面貌。
  3. 生命记忆价值：童年两地寄居、后来从北京带回餐具、亲人晚年改用实用碗等经历，使碗成为不同生活阶段与时间变化的记忆载体。
  4. 审美价值：玲珑碗的胎质与光影、廉价瓷碟的手工朴拙，给予“我”不同的观看、玩赏与使用体验。

审题与考查点

设问已排除盛放和加热食物等实用功能，需要概括碗在情感、生活文化、人生记忆和审美方面的意义，并使每一种意义都能回到具体材料。

文本分析

亲情与情感记忆查看证据 ↗

外公把热粥端给儿童，是物件进入亲情关系的具体动作；结尾又由碗回看外公笑容和家人团聚，明确承认这些关系对自己的滋养。情感价值来自器物所联系的人与共同生活，而非碗本身天然具有亲情。

  • 证据3 · 第15段大概做坏了不太规整，却有一种手工的朴拙。 ↗

知识点

小说物象：小说物象是作品中被着重呈现的非人物对象。器物、动植物等可参与人物生活、事件组织和情感表达，并在不同处境中获得新的意味。

散文中的哲理：散文中的哲理是作品从具体经历、感受和回顾中展开的、关于生命、处世或人与世界关系的较概括认识。它常与叙述、描写相结合，通过对经验的重新解释形成思考；其表达可以含有比喻和悖论，须在作品语境中理解。

文本证据与阅读推论：文本证据是能够支持某一理解的具体词句、叙事事实或结构关系。阅读推论则是依据这些材料，并借助适当的语言知识和事理作出的解释。

解题方法

先按外公外婆家、上海奶奶家、后来用碗和亲人晚年等范围圈出与碗有关的材料，再分别追问它让“我”记住谁、保留什么生活差异、标记何种经历、带来怎样的美感。把同类意义归在一起，以“价值类别＋相应材料”分条作答。

易误辨析

“碗能盛饭”“方便加热”仍是设问排除的实用功能；“象征家国”“身份危机”等结论没有充分依据。情感与记忆有联系，但回答时应分别说清亲人关系和人生阶段，避免两条都只写“承载回忆”。

答案组织与检核

逐条检查是否概括了不同价值，每一条至少对应一处具体材料；同时核对所举时间和经历，不把“第一次去北京”改写为北漂或定居。

第2题 · 语境与感悟

题目性质

选编题。

文中画波浪线的语句，你是如何理解的？请联系实际谈谈你的感悟。

参考答案2展开 / 收起

参考作答

  1. 句意上，“简朴”与“精致”概括不同的餐具、用餐方式及生活状态；“越来越近”“越来越遥远”说明生活条件与需要的改变会使某些旧日经验渐渐远去。
  2. 语境上，玲珑碗逐渐被便于使用的碗取代，与亲人老去、离散及奶奶独食相连。作者感慨时间流逝与旧日团聚难再，句中既有生活变化的无奈，也有对昔日美好日常的珍惜。
  3. 结合结尾，器物的精美固然值得珍赏，共处其中的亲人及其给予的滋养也需被看见。理解这句话不能只作简朴或精致的价值选择，还应体认生活背后的人情与时间。
  4. 联系实际示例：家中一次普通的晚饭，年轻人可能只注意菜好不好吃、餐具是否好看，忽略长辈的关切和共同聊天的时刻；离家以后，才发现这样的相聚越来越少。由此应学会在日常中回应亲人的关怀，珍惜仍能共处的时间。

审题与考查点

本题有解释语句和联系实际两个任务。先联系第16段亲人老去与独食的语境说明“两极”“近”“远”，再结合结尾对亲情的重新认识提出感悟；现实事例是对这一认识的说明。

文本分析

先落实两极的语境义查看证据 ↗

“简朴”与“精致”在前文可由粗瓷碗和玲珑碗的差别感知；到本段，不锈钢、塑料碗因方便使用而取代精美的旧碗。因此这两极首先指向具体生活样式，“近”“远”描述其中的变化，不能直接换算为道德优劣或贫富高下。

  • 证据1 · 第3段八仙桌上的碗多厚如陶盆 ↗
  • 证据2 · 第8段饭碗是青花小碗，薄薄的胎质，白润光滑 ↗
  • 证据3 · 第16段一种是不锈钢的，方便直接放到煤气灶上煮；一种是塑料的，方便微波炉加热。 ↗
  • 证据4 · 第16段日子无非是在简朴和精致的两极间来去，离某一极越来越近的同时，相应地，与另一极也就越来越遥远。 ↗

再辨老去与离散的感慨查看证据 ↗

语句之前的“零零落落”“病的病，离世的离世”以及奶奶独食，把器物的变化同家庭生活的消散联系起来。与旧日精致生活渐远，也意味着共同生活的人与相聚经验难以重现，故有时间不可返的惆怅；不能把奶奶使用塑料碗只解释为主动回归简朴。

  • 证据1 · 第16段我喜欢的带米粒的青花玲珑碗零零落落只剩下了几只 ↗
  • 证据2 · 第16段当初围成一桌的人，病的病，离世的离世，疏于来往的疏于来往，再无齐齐整整团聚的一天。 ↗
  • 证据3 · 第16段长年独自用餐，奶奶总是坐在窗前的旧藤椅上用一只勺子从塑料碗里慢慢地挖出饭食 ↗

以结尾限制价值判断查看证据 ↗

结尾承认童年只顾碗里的食物和碗的美，没有察觉亲人的关怀及团聚的意义。这一回看把理解的重心引向生活关系：器物可珍赏，人的相聚也值得珍惜。它并未推出精致必然损害真情，更没有要求读者抛弃审美追求。

  • 证据1 · 第18段就像幼时的我曾把全部注意力集中在那碗滚烫的粥上，集中在手里的玲珑碗上 ↗
  • 证据2 · 第18段却不曾察觉外公脸上的笑容，奶奶家笑着说着话的齐聚的家人，对我意味着什么，又滋养了我什么。 ↗

联系现实的相似关系查看证据 ↗

现实事例宜选择普通家庭共餐等与本文相关的情境，说明当时只注意物质细节，后来才认识到相聚有限。参考作答中的共餐情形是示例，不是原文记叙的另一件事。由有限的共同时间推出珍惜亲情，既有文本依据，也避免泛泛议论生活应该简朴还是精致。

  • 证据1 · 第18段这样的时刻，随着他的成年将越来越少。 ↗
  • 证据2 · 第19段谁也不知道三十余年后我们会变成怎样，也从来没有算过这样的相聚还有多久。 ↗

知识点

散文中的哲理：散文中的哲理是作品从具体经历、感受和回顾中展开的、关于生命、处世或人与世界关系的较概括认识。它常与叙述、描写相结合，通过对经验的重新解释形成思考；其表达可以含有比喻和悖论，须在作品语境中理解。

情感基调：情感基调是作品或语段中占主导地位、并贯穿多处表达的情感倾向，如沉郁、明快、悲凉或平和。

文本证据与阅读推论：文本证据是能够支持某一理解的具体词句、叙事事实或结构关系。阅读推论则是依据这些材料，并借助适当的语言知识和事理作出的解释。

解题方法

先把画线句中的“两极”落实到餐具和用餐方式，再读同段的亲人变化，确认“远去”的生活包含哪些人事。随后用结尾“却不曾察觉”的反思核验情感重心，最后选择一件相似的现实小事，写明情境、认识变化与感悟之间的联系。

易误辨析

只写“人生要在简朴与精致之间平衡”，会漏掉亲人老去与家庭离散的语境；把精致一律说成虚荣，也会与玲珑碗的美感描写相冲突。现实事例不必非凡，应与文本的相聚、忽略和后来体认形成可解释的联系。

答案组织与检核

答案应兼有语句释义、上下文情感与具体现实事例。检查所述感悟能否从所引材料推出，并保留眷恋、无奈、珍惜之间的层次，不把开放的体会写成唯一生活准则。
